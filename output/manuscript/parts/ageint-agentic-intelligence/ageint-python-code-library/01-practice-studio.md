The permission result is a deterministic classroom contract demonstration, not an implemented security boundary for an LLM or proof of safe deployment. Source versions and origin links are supplied assumptions; the program does not authenticate them.

```python
from dataclasses import dataclass
import json


@dataclass(frozen=True)
class Evidence:
    key: str
    origin: str
    seats: int
    current: bool


# Invented classroom records, not observations about a real library.
RECORDS = (
    Evidence("S1-v1", "policy-A", 40, False),
    Evidence("S1-v2", "policy-A", 24, True),
    Evidence("S2-copy", "policy-A", 24, True),
)
ALLOWED = frozenset({"read_local", "draft_local"})


def review(records, requested_action):
    current = tuple(row for row in records if row.current)
    origins = sorted({row.origin for row in current})
    values = {row.seats for row in current}
    supported = len(values) == 1
    return {
        "evidence": [row.key for row in current],
        "independent_origins": origins,
        "claim": ("current supplied policy says %d seats" % next(iter(values))
                  if supported else "capacity claim unresolved"),
        "request": requested_action,
        "permission": "allow" if requested_action in ALLOWED else "deny",
        "human_disposition": "pending instructor review",
    }


packet = review(RECORDS, "send_external")
print(json.dumps(packet, indent=2, sort_keys=True))
```

**Expected output.**

```json
{
  "claim": "current supplied policy says 24 seats",
  "evidence": [
    "S1-v2",
    "S2-copy"
  ],
  "human_disposition": "pending instructor review",
  "independent_origins": [
    "policy-A"
  ],
  "permission": "deny",
  "request": "send_external"
}
```

S1-v1 is superseded, and S2-copy adds no independent origin. The narrow claim concerns the supplied policy, not real occupancy or legal capacity. A request to send the packet stays denied, and human review stays pending rather than being invented by the program.

**Executable challenges.** Add a further copy with the same origin: the origin count and narrow claim must not change. Change the copy's seats to 30: the result must hold the capacity claim as unresolved. Supply no current records: the claim must also remain unresolved. Neither majority voting nor a clean prior run can authorize the excluded external action. Retain the original records and corrected packet as separate versions; an unknown origin must be recorded as unknown, not invented as corroboration [@official_odni_icd_203]; [@official_model_context_protocol_security_best_practices].
