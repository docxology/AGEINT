#### Lesson 1: LangChain/LangGraph: State Machine Orchestration

**Concept.** **LangChain/LangGraph: State Machine Orchestration** documents workflow stages with inputs, transforms, reviewers, and blocked actions at each handoff.

**Worked reasoning and limits.** Start with a framework-neutral contract: authorized → reading → checking → awaiting-review → accepted-local, with paused, rejected and cancelled exits. Every transition carries run/task ID, input version, accepted sources, pending work and decision owner; no graph edge grants a tool permission. A fixed policy packet can use a deterministic graph; adaptive next-passage selection is a separate behavior to justify and evaluate. [@scholarly_anthropic_building_effective_agents]

**Why it matters.** **LangChain/LangGraph** matters in the **Agentic AI Governance and Tool Security** lane because least-privilege agent design and run evidence must stay separate from judgment; treating pattern names as deployment playbooks is a common failure.
